## 三、数据库升级（按顺序执行）

```bash
cd /sugongdxt/testplatform
DBPWD=$(grep '^DB_PASSWORD=' .env | cut -d= -f2)
```

### 3.1 前置检查：申请单号查重

```bash
docker exec -i tp-mysql mysql -utestplatform -p$DBPWD test_platform -N \
  -e "SELECT app_no, COUNT(*) c FROM test_application GROUP BY app_no HAVING c > 1;"
```

**必须无输出**。如有重复单号，先人工修正历史数据，否则 3.2 唯一索引创建会失败。

### 3.2 单号唯一索引 + 邮件重试字段

```bash
docker exec -i tp-mysql mysql -utestplatform -p$DBPWD test_platform < deploy/alter_security_fix.sql
```

内容：`test_application.app_no` 唯一索引；`mail_log` 增加 `retry_count` 字段。
**只执行一次**，重复执行会报"索引/列已存在"。

### 3.3 用户组层级字段

```bash
docker exec -i tp-mysql mysql -utestplatform -p$DBPWD test_platform < deploy/alter_group_hierarchy.sql
```

内容：`sys_user_group` 增加 `parent_id` 字段及索引。
**只执行一次**，重复执行报"列已存在"可忽略。

## 四、重建服务

```bash

docker compose up -d --no-deps backend frontend
```

构建成功后才替换容器，替换期间服务短暂中断。**不要执行 `docker compose down`，不要重建 mysql/redis/minio。**

```bash
docker compose ps                       # backend/frontend 应为 Up
docker compose logs --tail=50 backend   # 确认 Spring Boot 启动完成、无异常
```
